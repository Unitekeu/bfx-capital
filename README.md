# BFX Capital — Trading Intelligence & Copy Trading

Clean, modern landing page for **BFX Capital**, a professional MetaTrader 5 signals + copy trading platform with strong risk management.

## Features

- Fully responsive design
- Clean and readable HTML structure
- Tailwind CSS (via CDN for simplicity)
- Modern dark theme
- Sections: Hero, Products, Copy Engine, Risk Management, Pricing, FAQ, CTA, Footer
- French content matching the original concept

## Tech Stack

- HTML5
- Tailwind CSS 3 (CDN)
- Inter font (Google Fonts)
- No build step required — open `index.html` directly

## How to use

1. Clone the repository
2. Open `index.html` in a browser
3. Or deploy to any static host (Vercel, Netlify, GitHub Pages, Cloudflare Pages…)

## Deploy (GitHub Pages example)

1. Go to repository **Settings → Pages**
2. Source: Deploy from a branch → `main` → `/ (root)`
3. Save

Your site will be available at:  
`https://unitekeu.github.io/bfx-capital/`
